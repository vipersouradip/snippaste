How to use it

The two builds are driven differently: on Windows the button comes to your text box, on Android a bubble floats above everything.

On Windows

In Chrome or Edge, on any website

  1. Hover or click into any text box — a small snip button appears in its corner.
  2. Click it, or press Alt+Shift+S.
  3. The Windows snipping overlay takes over the screen. Drag a box over anything — a PDF in Acrobat, a spreadsheet, a second monitor.
  4. Let go. The image is already in the text box. Press Enter.

Works in: ChatGPT, Gemini, Claude, Perplexity, Gmail, Notion — any page with a text box. Press Esc to cancel a snip.

On Android

In every app, including websites in Chrome

  1. Open SnipPaste once and tap Start bubble. A small bubble now floats above whatever you are doing — drag it anywhere.
  2. Open the app or website you want to type in and tap into its text box.
  3. Tap the bubble. The screen freezes; drag a box over any part of it.
  4. Let go. The snip is pasted into the field you were typing in.

Works in: anything on the device. It is not a browser add-on — it is a system-wide bubble, so ChatGPT/Gemini/Claude in Chrome and their standalone apps both work, as do WhatsApp, email and notes.

Before you install

Things worth knowing up front, rather than after.

Nothing leaves your machine. There is no network code in either build. Snips go straight from the screen into the text box.
Windows: the helper is compiled on your computer from the C# source in the zip, using the .NET compiler already present in Windows. No unsigned binary is downloaded, and it registers only for your user account.
Windows needs the Snipping Tool, which ships with every Windows 10 (1809+) and Windows 11 install. The helper opens it via ms-screenclip:.
Android 13+ hides the Accessibility toggle for sideloaded apps. If it looks greyed out: Settings → Apps → SnipPaste → ⋮ → Allow restricted settings. Without it, snips are copied to the clipboard and a share sheet opens instead of pasting automatically.
The Android build has not been run-tested. It compiles, packages and signs cleanly, and its manifest is correct, but it has never been exercised on real hardware. Treat the first run as a shakedown.
