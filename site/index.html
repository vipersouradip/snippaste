How it works

Snip, and it is already there

Windows is live today. Android and iOS take a different shape per platform.

On Windows

In Chrome, Brave or Edge, on any website

  1. Hover any text box — a snip button appears.
  2. Click to snip, or Alt+Shift+S. Hover for prompts: Explain, Answer, Summarise.
  3. Windows overlay takes over — drag over anything, even a second monitor.
  4. Release. Image + prompt are already in the box. Press Enter.

Works in: ChatGPT, Gemini, Claude, Grok, Perplexity — any text box. Esc to cancel.

On Android

Coming soon

Every app, including Chrome

  1. Tap Start bubble once.
  2. Tap bubble → screen freezes → drag a region.
  3. Snip pastes into the focused field.

Will work in: any app — Chrome, standalone apps, WhatsApp, email.

On iOS

Coming soon

Any app you can type in

  1. Add SnipPaste keyboard in Settings → General → Keyboard.
  2. Screenshot & crop the usual way.
  3. Switch to SnipPaste keyboard → tap snip to paste.

Why a keyboard: iOS forbids floating bubbles — keyboard is the only insertion point.

Install on Windows

Two steps, both one-time

Not on the Web Store — loads as unpacked. No admin rights.

1 · Load the extension

Chrome or Edge — identical

  1. Unzip somewhere you’ll keep it.
  2. Go to chrome://extensions (Brave: brave://extensions, Edge: edge://extensions).
  3. Turn on Developer mode (top-right).
  4. Load unpacked → pick the snippaste folder.
  5. Pin it from the puzzle menu.

Keep Developer mode on.

2 · Install the helper

Opens the Windows snip overlay

  1. Open native folder.
  2. Right-click install.ps1 → Run with PowerShell.
  3. It compiles & registers for Chrome/Edge.
  4. Restart Chrome completely.
  5. Green dot + Desktop helper ready = done.

Skip? Button still works — page-only. Remove via native\uninstall.ps1.
