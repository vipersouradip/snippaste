How it works

Snip, and it is already there

Windows is out now — the snip button comes to your text box. Android and iOS are on the way, and neither works quite the same: a bubble that floats above everything, and a keyboard you switch to.

On Windows

In Chrome or Edge, on any website

  1. Hover or click into any text box — a small snip button appears in its corner.
  2. Click it to snip, or press Alt+Shift+S. Rest on it instead and a short menu opens — Explain this, Answer this, Summarise this, Translate to English, Extract the text.
  3. The Windows snipping overlay takes over the screen. Drag a box over anything — a PDF in Acrobat, a spreadsheet, a second monitor.
  4. Let go. The image is already in the text box — along with the prompt you picked, if you picked one. Press Enter.

Works in: ChatGPT, Gemini, Claude, Perplexity, Gmail, Notion — any page with a text box. Press Esc to cancel a snip.

On Android

Coming soon

Planned: every app, including websites in Chrome

  1. Open SnipPaste once and tap Start bubble. A small bubble floats above whatever you are doing — drag it anywhere.
  2. Open the app or website you want to type in and tap into its text box.
  3. Tap the bubble. The screen freezes; drag a box over any part of it.
  4. Let go. The snip is pasted into the field you were typing in.

Will work in: anything on the device. It is not a browser add-on — it is a system-wide bubble, so ChatGPT/Gemini/Claude in Chrome and their standalone apps would both work, as would WhatsApp, email and notes.

On iOS

Coming soon

Planned: any app you can type in

  1. Add the SnipPaste keyboard once, in Settings → General → Keyboard.
  2. Take a screenshot the way you always do, and crop it to the part you want.
  3. In any app, tap into the text box and switch to the SnipPaste keyboard.
  4. Tap the snip. It goes into the field you were typing in.

Why a keyboard: iOS gives no app the right to float over others or to read the screen, so the bubble Android uses is impossible. A keyboard extension is the one place the system lets an app insert an image into whatever you are typing in.

Install on Windows

Two steps, both one-time

SnipPaste is not on the Chrome Web Store, so it loads the way any unpacked extension does — through Developer mode. Nothing here needs admin rights.

1 · Load the extension

In Chrome, or Edge — the steps are identical

  1. Unzip the download somewhere you will keep it. Chrome loads the extension from this folder every time it starts, and the helper stores its path — so if you move it later, you will need to re-run step 2.
  2. Open a new tab and go to chrome://extensions (on Edge, edge://extensions).
  3. Turn on Developer mode with the toggle in the top-right corner. Three buttons appear along the top of the page.
  4. Click Load unpacked, then pick the unzipped snippaste folder itself — the one containing manifest.json, not its parent.
  5. SnipPaste appears in the list. Click the puzzle-piece icon in the toolbar and pin it if you want the status popup within reach.

Keep Developer mode on. Chrome disables unpacked extensions when it is switched off, and may ask you to confirm them again after an update.

2 · Install the desktop helper

A small program that opens the Windows snip overlay

  1. Open the native folder inside the one you unzipped.
  2. Right-click install.ps1 and choose Run with PowerShell. If Windows blocks it, open PowerShell in that folder and run powershell -ExecutionPolicy Bypass -File install.ps1.
  3. It compiles the helper with the .NET compiler already on your machine, registers it for Chrome and Edge, and prints what it did. Everything stays under your user account.
  4. Restart Chrome completely — every window — so it picks the helper up.
  5. Click the SnipPaste icon. A green dot and Desktop helper ready means both steps worked.

Skipping this step? The button still works, but it can only snip the current page — not other apps. To remove the helper later, run native\uninstall.ps1.

Before you install

Worth knowing up front

A few things that are easier to read now than to discover later.

Nothing leaves your machine. There is no network code in either build. Snips go straight from the screen into the text box.
The Windows helper is compiled on your computer from the C# source in the zip, using the .NET compiler already present in Windows. No unsigned binary is downloaded, and it registers only for your user account.
Windows needs the Snipping Tool, which ships with every Windows 10 (1809+) and Windows 11 install. The helper opens it via ms-screenclip:
Android and iOS are not available yet. Android is being built and tested on real hardware; iOS has not started. Only the Windows download is live.
